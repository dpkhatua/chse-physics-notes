Units and Measurements

Before you measure the universe, learn to measure a pencil.

1 Physical Quantities & SI Units

A physical quantity is anything that can be measured — length, mass, time, temperature, current... Every measurement = a number + a unit. Say '10' without a unit and nobody knows if you mean 10 seconds or 10 kilometres!

The world agreed on one common system: the SI system (Système International) with 7 base units:

  • metre (m) — length
  • kilogram (kg) — mass
  • second (s) — time
  • ampere (A) — electric current
  • kelvin (K) — temperature
  • mole (mol) — amount of substance
  • candela (cd) — luminous intensity

Every other unit (speed, force, energy...) is a derived unit — built by multiplying/dividing base units. E.g. speed = m/s, force = kg·m/s² (this combination even gets its own name: newton).

⚠️ Don't lose marks: Writing an answer without units loses marks even if the number is correct — CHSE evaluators are strict about this in numerical answers.

2 Significant Figures & Errors

No measurement is perfectly exact — every instrument has a limit. Significant figures tell you how precisely a number is known.

  1. All non-zero digits are significant. (247 → 3 sig. figs.)
  2. Zeros between non-zero digits are significant. (2007 → 4 sig. figs.)
  3. Leading zeros are never significant. (0.0025 → 2 sig. figs.)
  4. Trailing zeros after a decimal point ARE significant. (2.500 → 4 sig. figs.)

Errors in measurement are of two broad kinds: systematic errors (same mistake every time — bad calibration, zero error) which can be corrected, and random errors (irregular, unpredictable) which we reduce by taking the mean of many readings.

📐 Combining errors
Addition/Subtraction → absolute errors add: Δ(A ± B) = ΔA + ΔB
Multiplication/Division → relative errors add: Δ(AB)/AB = ΔA/A + ΔB/B
✏️ Solved Example
Q. The radius of a sphere is measured as (2.1 ± 0.02) cm. Find the percentage error in its volume.
  1. Volume V = (4/3)πr³, so relative error in V = 3 × (relative error in r).
  2. Relative error in r = Δr/r = 0.02/2.1 = 0.00952
  3. Percentage error in V = 3 × 0.00952 × 100 = 2.86%
🎯 Answer: ≈ 2.86%

3 Dimensions & Dimensional Analysis

The dimension of a quantity shows which base quantities it's built from, written in square brackets. Force = mass × acceleration → [M L T⁻²].

📐 Dimensional formulae to remember
Velocity → [M⁰L¹T⁻¹]
Acceleration → [M⁰L¹T⁻²]
Force → [M¹L¹T⁻²]
Work / Energy → [M¹L²T⁻²]
Power → [M¹L²T⁻³]
Pressure → [M¹L⁻¹T⁻²]

Uses of dimensional analysis: (1) check if an equation is correct — dimensions on both sides must match (principle of homogeneity); (2) convert units from one system to another; (3) derive a relation between quantities.

✏️ Solved Example
Q. Check by dimensional analysis whether s = ut + ½at² is correct.
  1. [s] = [L]
  2. [ut] = [LT⁻¹][T] = [L]
  3. [at²] = [LT⁻²][T²] = [L]
  4. All three terms have dimension [L] — equation is dimensionally consistent.
🎯 Answer: Dimensionally correct (LHS = RHS = [M⁰L¹T⁰])
LimitationDimensional analysis can't find dimensionless constants (like 1/2 in ½mv²), and it fails for equations with trigonometric, exponential or logarithmic terms.
💡 Score booster: In the exam, always write the dimensional formula in the boxed [M L T] form — examiners award marks specifically for correct notation.

⚡ Quick Recap

  • Measurement = number + unit; SI has 7 base units.
  • Significant figures show precision; trailing zeros after a decimal point count.
  • Systematic errors can be corrected; random errors are reduced by averaging.
  • Dimensional analysis checks equations and derives relations — but misses numeric constants.

🎯 Exam Corner — practice in CHSE question style

Grouped the way CHSE papers weight questions. These are practice questions written in the board's style to test this chapter — not lifted from any specific year's paper.

1 mark
  1. Name the SI unit of luminous intensity.
  2. How many significant figures are there in 0.00580?
2 marks
  1. Distinguish between systematic and random errors, with one example each.
  2. Write the dimensional formula of (a) power (b) pressure.
3 marks
  1. The percentage errors in measurement of mass and speed are 2% and 3% respectively. Find the maximum percentage error in kinetic energy (KE = ½mv²).
5 marks
  1. What is dimensional analysis? State its three main uses and one limitation, with an example for each use.
